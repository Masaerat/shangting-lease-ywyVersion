# 智能租房 Agent 文档索引

## 推荐阅读顺序

1. 先读根目录 README，建立整体结构。
2. 按 `API → Agent → RAG → 预约 → MQ` 的顺序阅读面试手册。
3. 对照 API 文档完成一次后端手工测试。
4. 阅读 RAG 和 MQ 专题，重点理解指标口径、事务边界和失败场景。
5. 最后使用简历素材整理自己的表达，并用验证记录约束简历中的数据。

## 文档维护约定

- 代码行为优先于文档描述；功能变化必须同步更新相应专题和验证记录。
- 测试数量、模型效果和基础设施状态必须注明样本、环境和排除项。
- 不在文档中保存 API Key、数据库密码、JWT 或真实用户隐私信息。
- 新增专题应有独立职责，不再保存一次性执行计划、聊天进度或重复快照。
